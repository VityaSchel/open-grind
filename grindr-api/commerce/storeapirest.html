Get store-and-profile sections ​

Requires Authorization.

Server store and profile-drawer sections (cards, callouts, rows). DTOs have localization-key fields (titleId, subtitleId, bulletIds, ctaTextId, subtitleArgs), fallback to the literal title/subtitle/bullets/ctaText.

GET /v1/store-and-profile

Response:

  • sections — array of objects
    • type — string, section_header, active_subscription_row, card_carousel, callout_row, list_row, spacer, divider or micros_section
    • title — string
    • titleId — string
    • variant — string
    • theme — string
    • sku — string
    • productType — string
    • action — object
      • id — string
    • cards — array of objects
      • type — string, upgrade_card
      • theme — string
      • header — object
        • type — string
        • key — string
      • background — object
        • type — string
        • key — string
      • title — string
      • titleId — string
      • subtitle — string
      • subtitleId — string
      • bullets — array of strings
      • bulletIds — array of strings
      • ctaText — string
      • ctaTextId — string
      • sku — string
      • productType — string
      • action — object
        • id — string
    • icon — object
      • type — string
      • key — string
      • filled — boolean
    • subtitle — string
    • subtitleId — string
    • isNew — boolean

Create Edge invite ​

Requires Authorization.

POST /v1/invites

Body:

  • requestId — string, random UUID, reused when retrying the same request

Response:

  • invite — object
    • code — string
    • shareUrl — string
    • status — string
    • expiresAt — unix timestamp in milliseconds
  • remaining — integer, invites left

Claim Edge invite ​

Requires Authorization.

Redeems the code of an Edge invite. Invite links carry it as grindr://invite?code=<code>.

POST /v1/invites/claim

Body:

  • code — string

Response:

  • outcome — string, "GRANTED", "ALREADY_CLAIMED", "EXPIRED", "REVOKED", "INELIGIBLE", "PROGRAM_ENDED", "INVALID_CODE" or "SELF_CLAIM"
  • expiresAt — unix timestamp in milliseconds or null; null with INVALID_CODE

Errors:

  • 400 — urn:gr:err:internal_error when the body has no code.

    • vendorProductId — string

        • quantity — integer
      • iconId — string
      • subtitle — object
        • textId — string
        • quantity — integer
    • features — array of strings
    • includedFeatures — array of strings
  • products — ShopProductCatalog

CatalogProduct ​

  • vendorProductId — string
  • type — string, SUBSCRIPTION_PLAN or ONE_TIME_PURCHASE
  • duration — integer, duration in the unit given by interval
  • interval — string, MINUTE, HOUR, DAY, WEEK, MONTH or YEAR
  • trial — object or null
    • interval — string
    • duration — integer
  • consumable — object or null
    • name — string
    • type — string, IMMEDIATE_USE or INVENTORY
    • amount — integer, number of consumable units
  • roles — array of strings
  • isPeakTime — boolean
  • strikeThroughPriceSku — string or null
  • offerExpiresAt — integer, offer expiration time; sent by /v3/store/googleplay/products/store and shop routes; may be absent or null, optional
