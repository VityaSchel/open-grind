# Blocking and hiding profiles

## How to block users in Open Grind? {#block}

1. Open the profile
2. Tap the **⋯** menu
3. Tap **Block profile**

You can also tap **Block profile** right after you report someone.

To unblock, open the profile and tap **Unblock**, or turn it off in **Settings → Account Settings → Blocked users**.

## How to hide users in Open Grind? {#hide}

1. Open the profile
2. Tap the **⋯** menu
3. Tap **Hide profile**

To unhide, open the profile and tap **Unhide**, or turn it off in **Settings → Account Settings → Hidden users**.

## What's the difference between blocking and hiding users in Grindr? {#difference}

They have different **limits**.

|                                    | Block profile                             | Hide profile                                                                        |
| ---------------------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------- |
| Works on all profiles              | **[No](#why-cant-i-block-some-profiles)** | Yes                                                                                 |
| Reduces number of profiles you see | No                                        | **[Yes](https://help.grindr.com/hc/en-us/articles/35697847464467-Hiding-profiles)** |
| List cap                           | **Capped** at unknown number              | No cap                                                                              |
| Conversation                       | Cleared permanently                       | Comes back when unhidden                                                            |

Both make yours and theirs profile inaccessible and non-interactable for each other.

## Why can't I block some Grindr profiles? {#why-cant-i-block-some-profiles}

Grindr only lets you block people you've interacted with, for example chatted with. On other profiles, the official Grindr app shows **Hide** instead of **Block**.

Open Grind shows **Block** on every profile. Grindr usually accepts these blocks, but sometimes it ignores them. After you block someone, Open Grind checks your blocked list. If the profile isn't there, the profile comes back and you'll see "Blocking this profile failed".

When that happens, [hide the profile](#hide) instead.
