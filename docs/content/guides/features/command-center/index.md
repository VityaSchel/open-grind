# Command Center

Command Center in Open Grind is a central place for app navigation and quick actions. To open it, locate and tap the <img src="./command-center-trigger.webp" width="41.5" height="36" class="inline" alt="Feed input icon, “>_”"> button, at the end of filters top bar on the main "Browse" page. You can also use `⌘ + K` on macOS and `Ctrl + K` on Windows and Linux to open it.

<img src="./command-center-main.webp" width="408" height="273" style="margin-inline: auto" alt="Popup with “Quick actions...” input">

Learn about commands:

- Start with `#` to [open profile by id](./open-profile-by-id/)
- Start with `?` to [quickly filter the grid](./quick-filters-preset/)
- Start with `/` to [quickly go to a page](./quick-go-to/)
- Start with `@` to [teleport to a location](./quick-warp/)
