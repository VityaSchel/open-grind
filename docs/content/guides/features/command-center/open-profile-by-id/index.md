# Open Grindr profile directly by ID

To open a profile by ID in Grindr, use the [Command Center](/guides/features/command-center/).

First, copy the ID. Use the <img src="./profile-actions-button.webp" width="36" height="36" class="inline" alt="Profile actions, three vertical dots"> button on the profile page. In the menu, tap "Copy profile ID" and a large number will be copied to your clipboard, like this: `852120758`.

<img src="./profile-actions-menu.webp" width="196" height="125" style="margin-inline: auto">

With profile ID learned, locate the <img src="../command-center-trigger.webp" width="41.5" height="36" class="inline" alt="Feed input icon, “>_”"> button, at the end of filters top bar on the main "Browse" page. Tap it, which opens the Command Center. You can also use `⌘ + K` on macOS and `Ctrl + K` on Windows and Linux to open it.

<img src="../command-center-main.webp" width="408" height="273" style="margin-inline: auto" alt="Popup with “Quick actions...” input">

Finally, in the Command Center, put `#` and the profile ID after that, e.g. `#852120758`.

<img src="./command-center-open-profile-by-id.webp" width="408" height="165" style="margin-inline: auto" alt="“Open profile by id...” sub-menu of the popup">
